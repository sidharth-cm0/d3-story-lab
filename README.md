# D3 Story Lab

> **Emergent Narrative Simulation Platform — React SPA Edition**

D3 Story Lab is an emergent storytelling sandbox where narrative emerges organically from autonomous character interactions, bounded perception, evolving emotional states, and deterministic physics — converting verified simulation history into professional Fountain screenplays and storyboard shot plans.

---

## 🏗️ Core Architecture & Features

1. **Autonomous Simulation Sandbox**:
   - Canonical `WorldState` with strictly bounded spatial perception and line-of-sight.
   - Autonomous character decision loops with active goals, private secrets, and evolving beliefs.
   - Deterministic action validation with zero hallucinatory state mutation.
   - Step and Run simulation controls with an immutable chronological event log.

2. **Observer & Scribe Screenplay Engine**:
   - Observer Agent identifies dramatic turning points and clusters verified beats.
   - Scribe Agent composes production-grade Fountain (`.fountain`) screenplays with 100% event provenance.
   - Screenplay quality metrics (pacing curve, scene dialogue balance, action ratio).

3. **Storyboard Shot Planner**:
   - Automated cinematic shot planning with psychological camera angles (Low Angle, Dutch Angle, Over-the-Shoulder, Close-Up).
   - High-contrast procedural noir comic line-art SVG rendering with 16:9 framing.
   - 180° camera axis continuity tracking.

4. **Character Workstation & Field Authority**:
   - Dynamic character intake, normalization, and auto-enrichment.
   - Field-level authority management (`USER_LOCKED`, `USER_PREFERRED`, `SYSTEM_INFERRED`, `SYSTEM_GENERATED`).
   - Character dynamics (core values, conscious want, dramatic need, fears, moral boundaries).
   - Archetype inference & longitudinal archetype trajectory tracking.
   - Pairwise conflict graph across 10 distinct dramatic dimensions.

5. **Narrative Genome & Grounded RAG**:
   - Complete library of 15 canonical dramatic patterns.
   - Grounded RAG query answering citing verifiable event log evidence.
   - Director pacing recommendations.

6. **Temporal Character Graph**:
   - Interactive character relationship network with tick-by-tick time travel and diffing.
